# steam-freebooter-builds

Pre-built release binaries and injector libraries for `steam-freebooter`.

This repository hosts compiled `.so` files and installers for `steam-freebooter`. 
Releases are built automatically in the private source code repository and published here for public download.

## Features

- Fully compiled shared libraries (`sf-injector.i686.so` and `sf-injector.x86_64.so`).
- Stable releases linked directly to the configuration GUI manager.
